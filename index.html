Bank preset visual

Preset tersimpan di tablet dan dapat disinkronkan ke repository GitHub milikmu.

Analisis video referensi

Analisis otomatis tahap ini mengambil frame pada interval waktu untuk membantu pengamatan. Ia belum memahami semantik seluruh video atau mengenali semua keyframe secara otomatis. Gunakan catatan gaya untuk merumuskan resep yang bisa dipakai ulang.

Komposer video

Ekspor awal menggunakan MediaRecorder. Browser Android biasanya menghasilkan WebM; MP4 native belum dijanjikan.

Sinkronisasi GitHub

Gunakan fine-grained token dengan akses Contents: Read and write hanya pada satu repository khusus preset. Token hanya berada di memori tab ini dan tidak disimpan. Jangan gunakan token dengan akses seluruh akun.
File pusat: presets/library.json

Struktur bank preset

Preset adalah resep visual, bukan salinan konten video. Setiap preset menyimpan warna, tipografi, tempo, gerakan, transisi, dan tipe adegan yang disukai.
